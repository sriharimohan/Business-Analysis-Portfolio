# Omnichannel Retail Operations & Checkout Conversion Portfolio

## 📊 Project Overview
This repository contains an end-to-end business analysis and data portfolio demonstrating proficiency in **SQL data auditing, process mapping (FRDs & flowcharts), and executive visualization (Tableau)**. It models a realistic e-commerce retail dataset (~50,000 transactions) to identify revenue drivers and resolve checkout pipeline friction.

---

## 📂 Repository Structure
* **`SQL-Queries/`**: Contains database schema setup scripts, raw seed data, and data integrity/revenue aggregation queries.
* **`Process-Flows-and-Requirements/`**: Contains the Functional Requirements Document (`FRD_Online_Checkout.md`) and visual checkout workflow diagram (`checkout_workflow.png`).
* **`Dashboards/`**: Contains the executive summary briefing and live interactive dashboard reporting.
